Lista de Contatos
Projeto desenvolvido durante o curso Front-End da EBAC
📌 Sobre o Projeto

Este projeto foi desenvolvido como atividade prática do curso Front-End da EBAC.
O objetivo era criar uma lista de contatos simples, onde o usuário pode cadastrar um nome e número de telefone, exibindo os dados de forma clara e organizada.

A proposta do exercício era reforçar os conceitos de:

Manipulação do DOM

Estruturação de layouts

Captura e tratamento de dados do usuário

Uso de JavaScript para lógica básica

🧩 Funcionalidades

Adicionar um novo contato

Exibir a lista completa

Campos de nome e telefone

Layout simples, responsivo e organizado

Código leve e fácil de entender

🛠 Tecnologias Utilizadas
Front-End

HTML5

CSS3

JavaScript

🚀 Como Executar o Projeto
1. Clonar o repositório
git clone https://github.com/gabrielgomes28/contatos.git

2. Entrar na pasta do projeto
cd contatos

3. Executar

Basta abrir o arquivo index.html no navegador.

Não é necessário instalar dependências.
