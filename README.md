# Lista de contatos — HTML, CSS e JavaScript

Exercício de Front-End da EBAC para cadastro e exibição de contatos,
com manipulação do DOM e tratamento de entradas.

## Executar

```bash
git clone https://github.com/Gabrielpalhanogomes2803/agenda-de-contatos---html.git
cd agenda-de-contatos---html/contatos-main
```

Abrir index.html no navegador. Não há instalação de dependências para esta versão.
Opcionalmente, com Python 3, servir apenas no computador local:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Acessar http://127.0.0.1:8080 e encerrar com Ctrl+C.
